~ meters between sample points

      
Higher resolution means more, closer-together sample points -- but Open-Meteo's
        elevation data is itself only ~90m resolution, so sampling much finer than that just re-queries
        the same underlying pixels. Shrinking the bounding box (not just raising resolution) is what
        actually gets you closer to the ~90m floor; going below that needs a real high-res source
        (e.g. LiDAR), which you can supply yourself as a custom layer named "elevation" below. Higher
        resolution also means more live API calls -- 80 can take tens of seconds.
