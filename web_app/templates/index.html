Advanced options


    
    
    
~ grid points

    
The ground distance between sample points -- a smaller number means more,
      closer-together samples. Elevation requests try USGS 3DEP first (genuinely ~1m LiDAR-derived
      precision in the continental US), falling back to Open-Meteo (~90m) automatically if USGS is
      unavailable; sampling much finer than a source's own native resolution just re-samples the
      same underlying pixels. A smaller pixel size over a large box needs more grid points, which
      means more live API calls and a longer wait -- grid size is capped for practicality
      (much lower for USGS, since it has no batch endpoint).
